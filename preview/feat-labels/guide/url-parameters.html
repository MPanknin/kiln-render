URL parameters ​

The demo viewer reads its state from the URL; Share (top right) copies the current view as a link.

ParameterValuesDescription
datasetURLOME-Zarr or sharded binary dataset
sourceChannelszero-based indices, e.g. 5,11–4 source channels in display order (default: the first four)
timepointzero-based indexTimepoint (default 0)
modedvr, mip, iso, lod, sliceRender mode
wc, ww0–1Window centre and width
iso0–1Isosurface threshold
density0.1–10DVR opacity scale
shade0–1DVR gradient shading (default 0)
boundary0–1DVR boundary emphasis: opacity follows gradient magnitude (default 0)
tfgrayscale, grayscale-inverted, coolwarm, hot, cool, viridis, plasma, seismicTransfer function preset
tfptsx,y pairs, e.g. 0,0,0.5,0.8,1,1Transfer function opacity points
upx, y, z, -x, -y, -zCamera up axis
camrx,ry,dist,tx,ty,tzCamera rotation, distance and target
labelsname or URLLabel image drawn over the volume: a name from the dataset's labels group or an OME-Zarr URL (see Labels)
labelOpacity0–1How strongly label colours cover the image (default 0.5)
projorthoOrthographic projection for every view, quad panes included (default perspective; also the grid button under the orientation gizmo, or O)
scale0.25–1Render resolution scale
ssepixelsLOD screen-space error threshold (default 8; lower = sharper, more data)
pyramidnative, legacyLevel model. Default: native, falling back to legacy if the levels don't fit; setting it disables the fallback
clipMin, clipMaxx,y,z (0–1)Clip box
slicesx,y,z (0–1)Slice positions (slice mode)
sliceVis0–7Visible slice planes as a bitmask (X = 1, Y = 2, Z = 4; default 7)
wireframe, axis1Bounding box and axis overlays
layoutquadStart with front, side and top panes around the 3D view (single-channel viewer; also the grid button in the top bar, or Q). The axis panes pan and zoom but don't orbit; the controls set the 3D pane's mode and everything else for all panes
panesmodes, e.g. mip,dvr,sliceRender modes of the front, side and top panes: dvr, mip, iso, slice (default slice)

Changing Up Axis reorients and recenters the axis panes and updates their labels, including when you next open a hidden quad layout. Their render modes are kept; saved camera poses are restored only while the up axis is unchanged.

?dataset=https://example.com/scan.ome.zarr&mode=mip&wc=0.2&ww=0.3&tf=coolwarm

The multichannel viewer uses channels and slice instead of the single-channel display parameters: see Multichannel demo.

Diagnostics and experiments ​

Not included in share links.

ParameterDescription
debug=1Opens the stats panel (also D)
bench=1Once streaming and accumulation have converged, logs a report (timings, bytes, bricks) and sets window.__KILN_BENCH_RESULT. Options: benchLabel, benchTimeout (ms, default 120000), benchStable (polls, default 8), report=<url> to POST the JSON
rayguide=0Turns off ray-guided brick selection, which is on by default
local=trueSet by the viewer after opening a local directory; reopens it on reload
