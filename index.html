KilnInteractive exploration of large volumetric data, in the browser.

Kiln is a WebGPU renderer for large volumetric datasets. It streams multi-resolution data on demand within a fixed memory budget, so volumes that are impractical to download or convert can be explored and shared interactively.

Capabilities

OME-Zarr, no conversion needed

Compatible multiscale OME-Zarr (NGFF v0.4/v0.5) datasets stream directly from a URL or the local filesystem, with no Kiln-specific conversion. Other volumes can be converted to Kiln’s compressed sharded binary format.

Bounded GPU residency

Kiln streams into a bounded GPU residency/atlas cache sized to a configurable budget, resolved through virtual-texture indirection — see Architecture for the design

Bounded VRAM

An LRU brick cache capped at a configurable budget (~1.3 GiB by default). With more channels, the atlas is subdivided so total usage stays within budget on constrained GPUs.

Screen-space error LOD

Bricks are refined only when their projected voxel error exceeds a pixel threshold, adapting to resolution, field of view, and viewing distance.

Sharded-format range streaming

Kiln’s sharded binary format fetches individual bricks with HTTP Range requests. Bricks known to be empty from index statistics are never requested.

Compute-shader raymarching

Brick-aware DVR, MIP, isosurface, and slice rendering on a WebGPU compute pipeline, with temporal accumulation to reduce sampling noise.

uint8, uint16, float32 input

uint16 and float32 input are converted to r16float for GPU storage, with window/level controls. Up to 4 channels (beta) with per-channel color and windowing.

Under the hood

The streaming loop

Each frame, the streaming manager computes the set of bricks that should be resident and moves them through a worker pipeline into the atlas; requests for bricks that leave the desired set are cancelled. The full design is described in Architecture.

01

Select

Frustum-cull and rank bricks by screen-space error.

02

Fetch

Range-request missing bricks (Kiln’s sharded format), closest first.

03

Assemble

Workers decompress and re-chunk into 66³ bordered bricks.

04

Reside

Upload to an atlas slot and update the indirection table.

05

March

One compute thread per pixel traverses the resident bricks.

Getting started

Kiln is distributed as an npm package. A minimal viewer is a canvas, a dataset URL, and a KilnViewer.create call: 

import { KilnViewer } from 'kiln-render'

const canvas = document.querySelector('canvas')!
const viewer = await KilnViewer.create(canvas, 'https://example.org/data.ome.zarr')
viewer.mode = 'mip'
