# Code of Conduct

Kiln adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies to everyone participating in the project: in issues, pull requests, discussions, and any other project space, and when representing the project in public.

In short: be respectful and constructive, assume good faith, and keep discussion focused on the work. Harassment, personal attacks, and discriminatory language are not acceptable.

## Reporting

If you experience or witness behavior that violates the code of conduct, please contact the maintainer privately at **martinpanknin@gmail.com**. Reports will be handled confidentially.

The maintainer will review each report and respond as described in the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines), which range from a private warning to a permanent ban from the project.
