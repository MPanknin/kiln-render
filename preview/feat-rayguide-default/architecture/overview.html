System overview ​

Kiln separates the volume's address space from GPU memory, as in virtual texturing: a fixed-size atlas holds the bricks the current view needs, and the rest stays on the server until it is needed.

  • Virtual texturing: bricks, indirection table, atlas
  • Streaming manager: which bricks to load, in what order, and what to evict
  • Network & formats: HTTP Range streaming, compression, data types
  • Memory budget: VRAM accounting
  • Design decisions: why it is built this way
