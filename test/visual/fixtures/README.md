# Visual test fixtures

Small datasets committed for the visual tests and served by `../serve-data.mjs`.

- `hydrogen_atom.ome.zarr`: the hydrogen atom from the [Open SciVis Datasets](https://klacansky.com/open-scivis-datasets/)
  (originally volvis.org), 128³ uint8, as converted to OME-Zarr v0.5 (sharded, zstd) by the ome-zarr-scivis
  project: `https://ome-zarr-scivis.s3.us-east-1.amazonaws.com/v0.5/96x2/hydrogen_atom.ome.zarr`. Files are unchanged.
